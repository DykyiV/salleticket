# Структура і логіка сайту Asol BUS

Документ описує цільову структуру системи продажу квитків і статус
реалізації кожного розділу. Позначки: ✅ готово · 🔶 частково · ⬜ заплановано.

## 1. Пошук квитка ✅

Головна сторінка `/` — форма пошуку/бронювання:

- вибір типу перевезення (автобус / літак / потяг) перед полями «звідки/куди»;
- поля: звідки, куди, дата, кількість пасажирів;
- результати на `/results` з адаптерів перевізників (mock / mock-air / mock-rail);
- оформлення на `/booking` (гостьова форма), створення броні —
  `POST /api/booking` (потребує авторизації, редірект на `/login?next=…`);
- промокоди, вікові знижки, серверний перерахунок ціни, комісія агенства
  (snapshot на квитку), запис у історію квитка.

## 2. Мої квитки 🔶

Список квитків, відсортований за датою створення (нові зверху):

- `/account` — квитки поточного користувача ✅;
- `/agent` — квитки агента; за замовчуванням лише власні, з дозволом
  «view all tickets» (тумблер у `/admin/users`) — усі ✅;
- `/admin/tickets` — усі квитки системи ✅.

Пошук і фільтри:

- фільтр за статусом ✅ (`/admin/tickets?status=…`);
- пошук за референсом / ПІБ / телефоном / email ✅ (`?q=…`);
- фільтр за перевізником ✅ (`?carrier=…`);
- ⬜ фільтр за датою виїзду, за країною.

### 2.1. Відкриття квитка ✅

Клік по **прізвищу пасажира** (або референсу) у списку відкриває детальну
сторінку квитка: `/admin/tickets/[id]` (адмін), `/agent/tickets/[id]` (агент).

### 2.1.1. Деталі квитка ✅

- всі деталі рейсу (маршрут, виїзд/прибуття, тип транспорту) ✅;
- дані пасажира (ПІБ, телефон, email, тип квитка, промокод) з редагуванням
  (власник завжди; чужі — з дозволом «edit all tickets») ✅;
- усе про оплату: базова ціна, знижка, фінальна ціна, комісія агенства,
  частка перевізника, статус оплати (точка оплати: онлайн → гроші в агента,
  готівка → у перевізника) ✅;
- хто бронював (email + роль) ✅;
- дані перевізника і рейсу ✅;
- історія змін з diff'ами полів, автором, IP ✅;
- іконка відправки SMS пасажиру ✅ (адмін; mock-адаптер `lib/sms.ts`);
- коментарі до квитка (фіксація довільних нотаток з автором і часом) ✅;
- PDF-квиток з QR-кодом ✅.

## 3. Виїзди ✅

`/admin/departures` — перелік усіх виїздів:

- фільтр за країною (країна прибуття) ✅;
- фільтр за перевізником ✅;
- пошук за містами ✅;
- сортування: за часом виїзду, за вартістю ✅;
- календарик з періодом відображення (дата від / до; за замовчуванням —
  від сьогодні на місяць уперед) ✅.

### 3.1. Виїзд конкретний ✅

`/admin/departures/[id]` — усі пасажири рейсу, доступні користувачу:

- статистика рейсу (продано, виручка, комісія, за статусами) ✅;
- сортування пасажирів: за датою купівлі, за алфавітом, за містами
  (місто прибуття → час прибуття) ✅;
- чекбокси: масовий друк PDF і масові SMS ✅;
- детальна статистика вибраного квитка — перехід у `/admin/tickets/[id]` ✅.

## 4. Чат ⬜

`/admin/chat` — налаштування чат-ботів і розсилок:

- ⬜ сценарії чат-бота (FAQ, статус броні за референсом);
- ⬜ SendPulse інтеграція (API-ключ, ланцюжки);
- ⬜ Viber / WhatsApp канали (вибір провайдера, шаблони повідомлень);
- ✅ SMS-канал (mock-адаптер, готовий до підключення TurboSMS/Twilio).

## 5. Налаштування 🔶

`/admin/settings` — налаштування, доступні користувачу за роллю:

- ✅ керування користувачами і правами (`/admin/users`);
- ✅ комісійні правила (`/admin/commissions`);
- ✅ промокоди і знижки (`/admin/discounts`);
- ⬜ сервісний збір, валюта, контакти компанії;
- ⬜ особисті налаштування (зміна пароля, мова інтерфейсу).

## 6. Довідник ⬜

`/admin/directory` — довідники для кастомізації системи:

- ⬜ міста і країни (з мапінгом для фільтрів);
- ⬜ перевізники (картки, рейтинг, комісія за замовчуванням, контакти);
- ⬜ типи квитків і знижок;
- ⬜ шаблони SMS / email / документів.

## 7. Сайт ⬜

`/admin/site` — керування HTML-сторінками сайту:

- ⬜ редагування статичних сторінок (про нас, допомога, контакти, правила);
- ⬜ SEO-поля (title, description) по сторінках;
- ⬜ банери/оголошення на головній.

## 9. Звіти 🔶

`/admin/reports` — центр звітів:

- ✅ розрахунки з перевізниками: щомісячні settlements з рахунком і актом,
  автогенерація 7-го числа (cron), сальдо за точкою оплати, історія
  (GENERATED/SENT/PAID) — `/admin/settlements`;
- 9.1 ⬜ звіт агента: його пасажири, оборот, його % винагороди;
- 9.2 🔶 звіт для перевізника: усі пасажири перевізника з усього сайту
  (є у settlements); ⬜ галочка «розбити по агентах» — хто на яку суму
  бронював і яка його комісія;
- 9.3 ⬜ звіт для каси: усі пасажири, яким даний користувач зарахував кошти
  (фільтр історії статусів PAID_* за автором).

## 10. Статистика ⬜

`/admin/stats`:

- ⬜ продажі по перевізниках (квитки, оборот, комісія);
- ⬜ продажі по агентах;
- ⬜ продажі по країнах і містах;
- ⬜ графіки по днях/місяцях, топ-напрямки.
