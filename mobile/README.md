# Grandes Tour — мобільний додаток

Новий додаток Grandes Tour для iOS і Android на Expo (React Native,
TypeScript). Працює з новим сайтом продажу квитків з цього репозиторію через
його API. Виходить **оновленням наявного запису в App Store** (id 6447769469,
bundle id `com.devmetro.grandestour`), тому в кого стоїть старий додаток,
отримають новий автоматично.

## Що вже є (етап 1)

- Вхід і реєстрація тим самим e-mail і паролем, що й на сайті. Токен зберігається
  в Keychain / Keystore телефона й оновлюється при кожному запуску.
- «Мої квитки»: майбутні й минулі замовлення. Список оновлюється щоразу, коли
  відкриваєте вкладку, повертаєтеся в додаток або тягнете вниз, — квиток,
  куплений на сайті чи в касі, з'являється сам.
- Квиток: QR-код для водія на кожного пасажира, посадка й висадка з адресою і
  картою, місце, автобус, ціна, статус. Відкриті квитки зберігаються в
  телефоні й показуються без інтернету.
- Мови UA / ES / EN (як на сайті), назви міст перекладаються тим самим модулем,
  що й на сайті (`lib/trips/cities.ts`).

## Запуск для розробки

```bash
cd mobile
npm install
EXPO_PUBLIC_API_URL=http://<адреса-сайту> npx expo start
```

`EXPO_PUBLIC_API_URL` — адреса нового сайту без `/` в кінці. На телефоні
адреса має бути доступна з мережі (не `localhost`).

Перевірки (ті самі, що в CI):

```bash
npx tsc --noEmit
npx expo lint
npx expo export --platform ios --platform android --platform web
```

## API сайту, яким користується додаток

| Запит | Для чого |
|---|---|
| `POST /api/auth/login`, `POST /api/auth/register` з `client: "app"` | вхід / реєстрація; у відповіді `token` (30 днів) замість cookie |
| `POST /api/auth/refresh` | новий токен при запуску |
| `POST /api/auth/logout` | вихід (як на сайті — на всіх пристроях) |
| `GET /api/auth/me` | хто увійшов |
| `GET /api/me/tickets` | «Мої квитки»: `{ upcoming, past }` |
| `GET /api/tickets/<номер>` | е-квитки замовлення |

Токен передається заголовком `Authorization: Bearer <token>`; сервер перевіряє
його так само, як cookie сайту (роль і відкликання — з бази).
